# Instrucciones del proyecto — Sistema de Inventario

## Al iniciar cada sesion

Leer `HISTORIAL.md` para conocer el estado actual del proyecto y los cambios recientes antes de responder o modificar cualquier archivo.

## Al realizar cualquier cambio

Actualizar `HISTORIAL.md` al final de cada tarea con una entrada bajo la fecha del dia, describiendo que archivo se modifico y que se cambio. Usar el mismo formato de entradas existentes.
